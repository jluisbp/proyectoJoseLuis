# Guía del proyecto

Cómo hacer, paso a paso, cada tarea de tu proyecto. Esta carpeta crece con una guía por paso. La plantilla vive en [`plantilla-proyecto/`](../../plantilla-proyecto/) (raíz de este repositorio): es la **única copia**, no hay otra versión aquí.

## Cómo empezar

1. Crea tu repositorio de proyecto en tu cuenta de GitHub: `proyecto-daw-<tu-apellido>`.
2. Copia en él el contenido de [`plantilla-proyecto/`](../../plantilla-proyecto/). Para la sesión de Inicio basta con [`docs/00-documentoInicio.md`](../../plantilla-proyecto/docs/00-documentoInicio.md); el resto de plantillas las usarás según toque.
3. Rellena `docs/00-documentoInicio.md`.
4. Trabaja en una **rama**, haz commits con mensajes convencionales y abre un **Pull Request** a `main`. Tu primer PR lo revisa y lo aprueba el tutor; después lo integras tú. Desde el 19-nov, antes de cada hito, todos los PR esperan su aprobación (ver la hoja del hito).

El calendario y las fases están en [`../fases-del-proyecto.md`](../fases-del-proyecto.md) y la metodología en [`../metodologia.md`](../metodologia.md).
